# 🛴 Программный комплекс «Кикшеринг 42»

Десктопная система комплексного управления сервисом краткосрочной аренды электросамокатов (СИМ) в городской среде. Объединяет клиентский интерфейс проката с 2GIS-подобной картой, рабочий пульт техника с телеметрией Ninebot и полнофункциональный модуль администрирования реляционной базы данных.

---

## 📌 Основные возможности

### 👤 Клиентский сервис
* **Интерактивная карта города**: визуализация дорожной сети, тротуаров, зданий, ключевых POI-локаций и парковочных станций («P»).
* **Картографический выбор СИМ**: отображение процента заряда, радиуса хода и инвентарного номера при клике по маркеру.
* **Гибкая тарификация**: поминутные и пакетные тарифы.
* **Контроль сессии аренды**: живой посекундный таймер и динамический перерасчет стоимости поездки в реальном времени.
* **Фискализация**: автоматическая остановка аренды в разрешенной зоне с генерацией чека по формуле:
  $$\text{Итого} = 50\text{ ₽ (старт)} + (\text{минуты} \times 9{,}99\text{ ₽})$$
* **Обратная связь**: сохранение пользовательских оценок и текстовых отзывов (`Review`).

### 🔧 Модуль сервисного обслуживания (Пульт техника)
* **Поиск парка**: мгновенный переход к СИМ по инвентарному номеру или скану QR-кода.
* **Телеметрический пульт (Ninebot SL 90)**: онлайн-мониторинг GPS-координат, числа захваченных спутников, пинга связи и уровня заряда.
* **Дистанционная диагностика**: удаленное открытие и закрытие электромеханического замка со стойки самоката.
* **Умный регламент АКБ**: автоматическая подсветка аварийных СИМ (шестеренка дефекта) и программная блокировка ложной замены аккумулятора при заряде $> 20\%$.
* **Управление нарядами**: отслеживание сервисных задач (`Task`) с автоматическим закрытием наряда при обновлении емкости до $100\%$.

### ⚙️ Модуль системного администрирования
* **RBAC-модель доступа**: авторизация по связке телефон/пароль с разграничением ролей (Клиент, Техник, Администратор).
* **Горячая смена профиля**: переключение сессий через `CurrentUser.Reset()` без аварийного перезапуска процесса.
* **Прямой аудит БД**: табличный просмотр и фильтрация всех сущностей (`Users`, `Scooter`, `Parking`, `Rent`, `Task`, `Review`) через `DataGridView`.
* **Целостность данных**: каскадный контроль ссылочной целостности внешних ключей.

## 🚀 Быстрый старт

1. Установите [Microsoft Access Database Engine Redistributable](https://www.microsoft.com/download/details.aspx?id=54920) (разрядность драйвера должна строго совпадать с разрядностью сборки .NET).
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/kicksharing-42.git
   cd kicksharing-42
   ```
3. Перейдите в рабочий каталог сборки `bin/Debug/` и запустите `_42v2.exe`.
4. В окне входа авторизуйтесь под одной из предустановленных учётных записей.

## 🛠️ База данных и схема сущностей

Проект использует реляционную модель данных СУБД MS Access (`42.accdb`):
* `Users` — учетные записи, номера телефонов, роли и хэши паролей.
* `Scooter` — парк СИМ, текущие координаты $(X, Y)$, уровень заряда аккумулятора, статус (`Available`, `InUse`, `NeedsService`).
* `Parking` — точки официальных парковочных зон, координаты привязки, вместимость.
* `Rent` — журнал арендных сессий, метки времени старта/окончания, рассчитанная стоимость.
* `Task` — очередь регламентных и аварийных задач технического обслуживания.
* `Review` — отзывы клиентов и оценка качества поездок.

## 🚨 Возможные неполадки и их устранение

| Ошибка / Симптом | Причина | Решение |
| :--- | :--- | :--- |
| **«Файл 42.accdb не найден»** | БД перемещена или отсутствует в каталоге запуска | Скопируйте `42.accdb` в одну папку с `_42v2.exe` |
| **«Провайдер Microsoft.ACE.OLEDB.12.0 не зарегистрирован»** | Отсутствует системный OLEDB-драйвер или конфликт 32/64-bit | Установите *Access Database Engine* нужной разрядности |
| **«Невозможно добавление... нарушение целостности Parking»** | Попытка привязать СИМ к несуществующему `ParkingID` | Указывайте существующий ID парковки ($1..5$) или добавьте новую запись |
| **«Этот самокат разряжен и ожидает ТО»** | Попытка взять в аренду СИМ с зарядом $\le 20\%$ | Выберите другой самокат на карте либо проведите ТО под ролью техника |
| **Кнопка «Заменить АКБ» неактивна (серая)** | Заряд СИМ $> 20\%$ и нет ошибок | Программно заблокировано во избежание необоснованного ТО |
| **Вместо иконки самоката рисуется текстовый маркер** | Отсутствует файл `123.ico` в рабочей директории | Поместите `123.ico` в корень исполняемого каталога |
